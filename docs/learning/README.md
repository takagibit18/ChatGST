# ChatGST Learning Notes

This directory collects the supplemental study notes from the local `ChatGST-技术学习资料包`.
They are kept as reference material and are not imported by the runtime build.

| Path | Purpose |
| --- | --- |

| `source-index.md` | Bridge source map and module navigation. |
| `ontology-agent-architecture-notes.md` | Ontology agent architecture notes. |
| `ontology-platform-business-notes.md` | Ontology platform features and business workflow notes. |
| `multi-source-normalization-pipeline.md` | Multi-source document normalization pipeline design. |
| `performance-notes.md` | Performance observations. |
| `project-qa.md` | Project Q&A notes. |
| `bridge-src/` | Markdown source walkthrough for the bridge service modules. |
