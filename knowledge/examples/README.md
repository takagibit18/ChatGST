# Knowledge Examples

This directory contains small, versioned examples from the supplemental learning package. Unlike `knowledge/raw`, these files are not live policy corpora and are safe to keep as architecture examples.

| Directory | Contents |
| --- | --- |
| `ontology-skeleton/` | Concept, operator, manifest and metadata skeleton examples for the childcare subsidy ontology. |
| `okf-output/` | Example OKF Markdown outputs and conversion logs. |

Do not place production policy corpora, generated RAG indexes, or evidence-bearing private datasets here. Those remain local-only under the ignored knowledge directories described in `knowledge/README.md`.
